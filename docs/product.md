# محصول و تجربهٔ کاربری

## مسئله و هدف

کاربر می‌خواهد کارهایش روی چند دستگاه در دسترس باشند، بدون راه‌اندازی سرور یا پایگاه داده. GitHub نقش ذخیره‌سازی و تاریخچهٔ تغییرات را دارد، نه یک سیستم هویت یا پایگاه دادهٔ چندمستاجری. نسخهٔ اول برای استفادهٔ شخصی و حجم کم داده طراحی می‌شود، نه همکاری تیمی یا اطلاعات بسیار حساس.

## سفر کاربر

1. صفحهٔ خوش‌آمدگویی کاربرد، محدودیت‌ها و ریسک توکن را به زبان ساده توضیح می‌دهد. کاربر به GitHub راهنمایی می‌شود تا مخزن خصوصی خود را بسازد و یک fine-grained personal access token محدود به همان مخزن و مجوز موردنیاز ایجاد کند. سایت اعتبارنامهٔ GitHub را دریافت نمی‌کند؛ فقط خود توکن را در یک ورودی امن می‌گیرد.
2. برنامه با API هویت و دسترسی را بررسی می‌کند، مخزن و شاخه را نشان می‌دهد و پیش از ایجاد فایل، رضایت می‌گیرد. در صورت خطا علت و راهنمای اصلاح نمایش داده می‌شود. سپس کاربر یک گذرعبارت برای قفل محلی توکن تعیین می‌کند.
3. در ورود بعدی روی **همان مرورگر و دستگاه**، گذرعبارت قفل محلی را باز می‌کند. دستگاه جدید به توکن معتبر و تنظیم قفل محلی نیاز دارد؛ داده‌ها از مخزن خصوصی همان حساب دریافت می‌شوند.
4. کاربر کارها را اضافه، ویرایش، تکمیل، بازگشایی و حذف می‌کند؛ وضعیت ذخیره و آخرین همگام‌سازی همیشه مشخص است. در تنظیمات می‌تواند گذرعبارت محلی را تغییر دهد، قفل کند، از دستگاه خارج شود و توکن را جایگزین کند.

## امکانات نسخهٔ اول

- عنوان اجباری، توضیح اختیاری، تاریخ سررسید اختیاری، اولویت و زمان‌های ایجاد و به‌روزرسانی؛ شناسهٔ یکتا و وضعیت انجام.
- نماهای همه، فعال و انجام‌شده؛ جست‌وجو و مرتب‌سازی بر اساس تاریخ و اولویت. نمایش خالی مفید و تأیید پیش از حذف.
- بازخورد فوری، تفکیک تغییرات محلیِ ذخیره‌نشده از تغییرات همگام‌شده، تلاش مجدد و راهنمای حل تعارض. دادهٔ معیوب هرگز خودکار بازنویسی نشود.
- طراحی واکنش‌گرا، فارسی و راست‌به‌چپ، پشتیبانی از صفحه‌کلید، برچسب ورودی‌ها، کنتراست مناسب و اعلام وضعیت برای صفحه‌خوان.
- گرادیان نرم و متحرک بدون ایجاد اختلال در خوانایی؛ احترام به `prefers-reduced-motion` و نمایش ثابت برای کاربران حساس به حرکت.

## خارج از محدودهٔ نسخهٔ اول

همکاری چندنفره، اعلان قابل اعتماد در پس‌زمینه، تکرار خودکار کارها، پیوست، بازیابی رمز، اپ موبایل بومی و ادعای رمزنگاری سرتاسری کارها. افزودن هر کدام نیازمند طراحی جداگانه است. فایل کارها در مخزن خصوصی به صورت JSON معمولی ذخیره می‌شود و هر کسی که به مخزن دسترسی دارد می‌تواند آن را بخواند.
