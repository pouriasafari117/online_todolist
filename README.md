# دفتر آرام

طرح یک تودولیست شخصی با رابط فارسی، پس‌زمینهٔ آرام و همگام‌سازی از طریق همین مخزن GitHub. نسخهٔ اولیهٔ سایت پیاده‌سازی شده است.

در نسخهٔ اول، مالک مخزن در دستگاه اول یک توکن fine-grained محدود به همین مخزن وارد و یک گذرواژه تعیین می‌کند. نسخهٔ رمزگذاری‌شدهٔ توکن در مخزن عمومی ذخیره می‌شود تا دستگاه‌های دیگر با گذرواژه به آن دسترسی پیدا کنند. کارها به صورت معمولی و عمومی در همین مخزن ذخیره می‌شوند. این تصمیم برای استفادهٔ شخصی با پذیرش ریسک از طرف مالک است، نه برای میزبانی چند کاربر.

## اجرا و آزمایش

برای اجرای محلی، از ریشهٔ پروژه `npm start` را اجرا کنید و `http://localhost:8000` را باز کنید. برای انتشار، فایل‌های سایت را روی میزبانی استاتیک HTTPS (مثلاً GitHub Pages) قرار دهید. مرورگر برای Web Crypto به محیط امن نیاز دارد. آزمون‌های واحد با Node.js 20 یا جدیدتر: `npm test`.

**شاخهٔ داده:** در اجرای محلی با `npm start`، شاخهٔ checkout فعلی به صورت خودکار استفاده می‌شود. در GitHub Pages، گردش کار موجود هنگام انتشار نام شاخهٔ منتشرشده را در تنظیمات سایت قرار می‌دهد؛ پس بعد از ادغام و انتشار نسخهٔ `main`، سایت از `main` استفاده می‌کند. هنگام ورود فهرست شاخه‌های موجود از GitHub دریافت می‌شود و کاربر شاخه را انتخاب می‌کند؛ شاخهٔ اجرا، اگر در فهرست باشد، به‌صورت پیش‌فرض انتخاب می‌شود. هر تغییر داده مستقیماً روی همان شاخه commit می‌شود، حتی در پیش‌نمایش.

برای GitHub Pages در تنظیمات مخزن، بخش **Pages** و گزینهٔ **Source: GitHub Actions** را انتخاب کنید. گردش کار `.github/workflows/pages.yml` با push کد یا اجرای دستی روی شاخهٔ انتخابی سایت را می‌سازد. همهٔ شاخه‌ها یک آدرس Pages مشترک دارند؛ آخرین انتشار موفق تعیین می‌کند سایت کدام شاخه را نمایش دهد. تغییرات صرفاً داخل `data/` انتشار مجدد را اجرا نمی‌کنند. فعال‌سازی Pages و تست انتشار هنوز انجام نشده است. در میزبان استاتیک بدون تنظیمات build نیز کاربر شاخه را از فهرست انتخاب می‌کند.

ادغام PR فقط commitهای موجود در آن هنگام ادغام را منتقل می‌کند؛ اگر داده‌ها بعداً روی شاخهٔ قدیمی تغییر کنند به‌طور خودکار به شاخهٔ مقصد منتقل نمی‌شوند. تغییر هم‌زمان داده در دو شاخه می‌تواند تعارض Git ایجاد کند و باید هنگام ادغام بررسی شود.

در تعارض همگام‌سازی، ذخیره متوقف می‌شود و می‌توانید نسخهٔ محلی را دانلود کنید یا با تأیید خودتان نسخهٔ GitHub را جایگزین کنید؛ ادغام خودکار هنوز پیاده‌سازی نشده است.

## شخصی‌سازی و بازخورد

در تنظیمات می‌توانید از چهار پالت پس‌زمینه انتخاب کنید و صداهای کوتاه رابط را روشن یا خاموش کنید. این انتخاب‌ها فقط در مرورگر فعلی ذخیره می‌شوند و همراه کارها بین دستگاه‌ها همگام نمی‌شوند. با تکمیل هر کار، کاغذ رنگی نمایش داده می‌شود؛ برای تنظیم «کاهش حرکت» در سیستم، انیمیشن‌ها و کاغذ رنگی غیرفعال‌اند. مرورگر ممکن است تا نخستین تعامل کاربر پخش صدا را اجازه ندهد.

صفحهٔ ورود گزینه‌های ورود و ساخت حساب را نمایش می‌دهد؛ نسخهٔ فعلی همچنان یک دفتر برای هر شاخه دارد و ساخت حساب دوم یا ورود چندکاربره را پشتیبانی نمی‌کند.
