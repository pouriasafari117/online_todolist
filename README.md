# دفتر آرام

طرح یک تودولیست شخصی با رابط فارسی، پس‌زمینهٔ آرام و همگام‌سازی از طریق همین مخزن GitHub. نسخهٔ اولیهٔ سایت پیاده‌سازی شده است.

در نسخهٔ اول، مالک مخزن در دستگاه اول یک توکن fine-grained محدود به همین مخزن وارد و یک گذرواژه تعیین می‌کند. نسخهٔ رمزگذاری‌شدهٔ توکن در مخزن عمومی ذخیره می‌شود تا دستگاه‌های دیگر با گذرواژه به آن دسترسی پیدا کنند. کارها به صورت معمولی و عمومی در همین مخزن ذخیره می‌شوند. این تصمیم برای استفادهٔ شخصی با پذیرش ریسک از طرف مالک است، نه برای میزبانی چند کاربر.

## اجرا و آزمایش

برای اجرای محلی، از ریشهٔ پروژه `npm start` را اجرا کنید و `http://localhost:8000` را باز کنید. برای انتشار، فایل‌های سایت را روی میزبانی استاتیک HTTPS (مثلاً GitHub Pages) قرار دهید. مرورگر برای Web Crypto به محیط امن نیاز دارد. آزمون‌های واحد با Node.js 20 یا جدیدتر: `npm test`.

**توجه:** برنامه داده‌ها را مستقیماً در شاخهٔ `arena/22980cc3-online-todolist` همین مخزن می‌نویسد؛ حتی هنگام استفاده از پیش‌نمایش، ورود توکن و انجام تنظیمات به تغییر فایل‌های واقعی در همین شاخه منجر می‌شود. نیازی به ادغام در `main` یا ساخت PR نیست.

برای انتشار دائمی بدون PR، در تنظیمات مخزن در بخش **Pages**، منبع را روی **Deploy from a branch**، شاخه را روی `arena/22980cc3-online-todolist` و پوشه را روی `/ (root)` بگذارید و ذخیره کنید. GitHub پس از ساخت، نشانی سایت را همان‌جا نشان می‌دهد. هر commit داده در این شاخه ممکن است انتشار دوبارهٔ Pages را آغاز کند. قبل از فعال‌سازی، تنظیمات و دسترس‌پذیری Pages در حساب GitHub بررسی شود.

در تعارض همگام‌سازی، ذخیره متوقف می‌شود و می‌توانید نسخهٔ محلی را دانلود کنید یا با تأیید خودتان نسخهٔ GitHub را جایگزین کنید؛ ادغام خودکار هنوز پیاده‌سازی نشده است.
