# دفتر آرام — طرح یک تودولیست همگام با GitHub

دفتر آرام یک **طرح در مرحلهٔ مستندسازی** برای مدیریت کارهای روزمره است: رابطی آرام و واکنش‌گرا، با پس‌زمینهٔ گرادیان متحرک و ذخیره‌سازی مبتنی بر GitHub. در این مرحله هنوز سایت یا سیستم ورود پیاده‌سازی نشده است.

## تصمیم مهم مهندسی

یک مخزن مشترک نمی‌تواند با یک توکن دارای دسترسی نوشتن، فایل هر کاربر را از سایر نویسندگان همان مخزن محافظت کند. همچنین یک سایت کاملاً ایستا نمی‌تواند صرفاً با رمز عبور، بدون دریافت یک راز یا استفاده از سرویس واسط، به فایل خصوصی GitHub روی دستگاه جدید دسترسی پیدا کند. به همین دلیل طرح پیشنهادی برای نسخهٔ اول از **یک مخزن خصوصی مستقل متعلق به هر کاربر** و یک توکن محدود به همان مخزن استفاده می‌کند. رمز عبور فقط قفل محلی توکن روی همان دستگاه است؛ برای دستگاه جدید باید توکن مجدداً ارائه شود. جزئیات، مصالحه‌ها و مسیرهای جایگزین در مستندات آمده‌اند.
