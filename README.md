# دفتر آرام

طرح یک تودولیست شخصی با رابط فارسی، پس‌زمینهٔ آرام و همگام‌سازی از طریق همین مخزن GitHub. فعلاً پروژه در مرحلهٔ مستندسازی است و سایت هنوز پیاده‌سازی نشده است.

در نسخهٔ اول، مالک مخزن در دستگاه اول یک توکن fine-grained محدود به همین مخزن وارد و یک گذرواژه تعیین می‌کند. نسخهٔ رمزگذاری‌شدهٔ توکن در مخزن عمومی ذخیره می‌شود تا دستگاه‌های دیگر با گذرواژه به آن دسترسی پیدا کنند. کارها به صورت معمولی و عمومی در همین مخزن ذخیره می‌شوند. این تصمیم برای استفادهٔ شخصی با پذیرش ریسک از طرف مالک است، نه برای میزبانی چند کاربر.
